# Local fonts

Downloaded 2026-10-10 from Google Fonts' official CSS/WOFF2 service. These files are bundled runtime assets; the website makes no Google Fonts request.

- `syncopate-latin-700.woff2`: Syncopate, normal 700, Latin. Google Fonts v24; Apache-2.0 license in `Syncopate-LICENSE.txt`.
- `manrope-latin-variable.woff2`: Manrope, normal variable 400–800, Latin. Google Fonts v20; SIL OFL 1.1 in `Manrope-OFL.txt`.
- `jetbrains-mono-latin-variable.woff2`: JetBrains Mono, normal variable 400–600, Latin. Google Fonts v24; SIL OFL 1.1 in `JetBrainsMono-OFL.txt`.

Font source and license repository: https://github.com/google/fonts (`apache/syncopate`, `ofl/manrope`, `ofl/jetbrainsmono`). WOFF2 CSS source: https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&family=JetBrains+Mono:wght@400..600&family=Syncopate:wght@700&display=swap .

Latin subsets cover the English interface. Other scripts in user-supplied token names use the CSS system fallback.
